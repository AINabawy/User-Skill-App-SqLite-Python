# 🧑‍💻 User Skill Management App

A simple Python-based command-line application to manage users and their skills using an SQLite database.

## 📌 Overview

This app allows you to:
- Add and update user skills
- View all skills for a specific user
- Delete users or specific skills

It’s a beginner-friendly CRUD (Create, Read, Update, Delete) project that practices database interaction with SQLite and core Python logic.

## 🛠️ Tech Stack

- **Language**: Python 3.7.6
- **Database**: SQLite3 
- **Tools**: SQLite3 module
